# MCP Express Authorization

MCP Express provides secure and centralized authorization methods for connecting AI tools to your server. By configuring your tool with either OAuth or Client Credentials, you can ensure safe, seamless access to all published tools while maintaining control over your environment.

These authorization methods support multiple AI clients, enabling consistent configuration across desktops, IDEs, and other platforms. Whether you are authorizing a single user or deploying tools across a team, MCP Express simplifies server access and management.

## Available Authorization Methods

- **OAuth Authorization**: Connect your AI tool via the standard OAuth flow to access tools on your authorized server.
- **Client Credentials**: Use a Client ID and Client Secret to configure AI tools for server access, ideal for automated or non-interactive workflows.
