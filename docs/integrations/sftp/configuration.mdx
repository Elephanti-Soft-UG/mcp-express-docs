# Configuration

Configuration defines how MCP Express exposes SFTP operations as callable tools. Each tool uses a base connection plus an `action` field to select the operation at runtime.

## Tool Orchestration
SFTP uses an action-oriented setup. A single tool can perform different operations by switching the `action` field while retaining shared connection settings.

## Configuration Setup
Define the connection scope once, then configure the action-specific fields for each tool.

### Base Connection Fields

| Parameter | Description | Required |
| --- | --- | --- |
| hostname | SFTP server hostname or IP address. | Yes |
| port | SFTP port (Default: 22). | Optional |
| username | Username for authentication. | Yes |
| password | Password for authentication. | Yes (alternatively with private_key) |
| private_key | Path to SSH private key. | Yes (alternatively with password) |

### Template Variables
Paths and content fields support Jinja2 templates. Provide variables through the tool `args` object.

```json
{
  "config": {
    "action": "read",
    "hostname": "sftp.example.com",
    "username": "user",
    "password": "password",
    "remote_file_path": "/data/{{ year }}/{{ month }}/report.csv"
  },
  "args": {
    "year": "2024",
    "month": "01"
  }
}
```

### How It Works
- Select an `action` (search, list, read, write, upload, download).
- Provide the action-specific fields such as `remote_path` or `remote_file_path`.
- Use Jinja2 placeholders to inject runtime values where needed.
- Validate behavior with representative payloads before enabling the tool.

### Supported Actions

#### Search
Find files matching a pattern within a directory.

**Key fields:**
- `remote_path`: Directory to search.
- `pattern`: Wildcard pattern (Default: `*`).
- `recursive`: Enable subdirectory traversal.
- `max_results`: Cap the number of returned items.

```json
{
  "action": "search",
  "remote_path": "/uploads",
  "pattern": "*.log",
  "recursive": true,
  "max_results": 100
}
```

#### Read
Read file contents. Use `encoding` to control output format.

**Key fields:**
- `remote_file_path`: File to read.
- `encoding`: `auto`, `text`, or `binary`.

```json
{
  "action": "read",
  "remote_file_path": "/data/config.json",
  "encoding": "auto"
}
```

#### Write
Write text content to a remote file.

**Key fields:**
- `remote_file_path`: Destination file path.
- `file_content`: Content to write.
- `encoding`: File encoding (Default: `utf-8`).
- `overwrite`: Overwrite existing file.

```json
{
  "action": "write",
  "remote_file_path": "/data/output.txt",
  "file_content": "Content to write",
  "encoding": "utf-8",
  "overwrite": true
}
```

#### Upload
Upload a local file to the remote server.

**Key fields:**
- `local_file_path`: Source file on the MCP server host.
- `remote_file_path`: Destination on the SFTP server.
- `overwrite`: Overwrite existing file.

```json
{
  "action": "upload",
  "local_file_path": "/home/user/document.pdf",
  "remote_file_path": "/uploads/document.pdf",
  "overwrite": false
}
```

#### Download
Download a remote file to the local system.

**Key fields:**
- `remote_file_path`: File to download.
- `local_file_path`: Destination on the MCP server host.
- `overwrite`: Overwrite existing file.

```json
{
  "action": "download",
  "remote_file_path": "/backups/data.tar.gz",
  "local_file_path": "/home/user/downloads/data.tar.gz",
  "overwrite": true
}
```

#### List
List files and directories for a given path.

**Key fields:**
- `remote_path`: Directory to list.
- `recursive`: List subdirectories.
- `include_hidden`: Include dotfiles.
- `max_results`: Cap the number of returned items.

```json
{
  "action": "list",
  "remote_path": "/data",
  "recursive": false,
  "include_hidden": false,
  "max_results": 1000
}
```
