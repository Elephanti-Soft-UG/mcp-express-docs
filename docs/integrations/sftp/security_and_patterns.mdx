# Security & Implementation Patterns

Use these controls to run SFTP-backed tools safely in production. The goal is to maintain least-privilege access, predictable filesystem scope, and bounded execution time.

## Guardrails & Restricted Operations
Restrict tools to approved base directories and prefer read-only operations where possible. Limit `write`, `upload`, and `delete`-like workflows to controlled paths.

:::danger Unbounded Paths Can Expose Sensitive Data
Unvalidated `remote_path` or `remote_file_path` values can allow access to unexpected directories. Treat all templated inputs as untrusted and enforce allowlists.
:::

Runtime note: In this integration, Jinja2 placeholders are the dynamic input mechanism. Any value injected through templates should be validated before execution.

## Authentication Hardening
- Prefer key-based authentication over passwords for production environments.
- Store private keys in a secure location with file permissions set to 600.
- Use a dedicated service account with limited access to required directories only.

## Data Governance & Scopes
- Allowlist base directories and reject relative path traversal sequences.
- Enforce distinct directories for uploads versus processed output.
- Log operation metadata (action, path, user) for auditability.
- Disable recursive listing when the directory depth is large or unknown.

## Performance Optimization

| Pattern | Description | Benefit |
| --- | --- | --- |
| Bounded Results | Keep `max_results` conservative for search and list operations. | Prevents oversized responses. |
| Targeted Patterns | Use specific patterns instead of broad wildcards. | Reduces scan time. |
| Limited Recursion | Disable or cap recursive listings. | Avoids long-running traversals. |
| Chunked Files | Split large file reads or downloads when possible. | Keeps responses within size limits. |

## Protocol Limitations
- Very large files can exceed response size limits when returned as inline content.
- Binary content may require explicit `encoding` selection for predictable output.
- Deep recursion across large directories can exceed operational timeouts.
