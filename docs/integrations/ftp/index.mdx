# FTP Integration

The FTP integration connects MCP Express to file servers over FTP, enabling controlled file operations with schema-validated inputs and clear auditability.

## Capabilities
- **Remote File Operations**: Search, list, read, write, upload, and download files on FTP servers.
- **Template-Driven Paths**: Use Jinja2 variables to build dynamic paths and filenames at runtime.
- **Connection Validation**: Verify connectivity and credentials before activating tools.
