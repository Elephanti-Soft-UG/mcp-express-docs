# PostgreSQL Integration for MCP Server

Grant your AI assistants secure access to your PostgreSQL database.

The PostgreSQL integration enables AI assistants to execute queries directly on your database, streamlining data retrieval and analysis workflows.

![Claude Answering Queries By Checking Postgres Database](../../images/claude_answering_user_queries_quick-start-guide.gif)

## Capabilities

- **Read-only mode** – to explicitly prevent any write operations
- **Analytics for tool** – see what queries your AI agent has actually run along with the prompt
- **Allow table access but block specific sensitive columns** – e.g., passwords, SSNs
- **Query the database without running any SQL** - ask your AI agent in natural language to get answers
- **Instant database information** – right from your AI chat interface
- **Dynamic Query Execution from AI** - allow your AI to execute queries based on your requirements without having to write queries yourself
