# Google Analytics Integration

To connect MCP Express to your Google Analytics 4 (GA4) property, you need a Google Cloud service account with access to the Google Analytics Data API and at least Viewer-level access on your GA4 property. This integration authenticates entirely through a service account JSON key — no OAuth flow or user login is required.

Once connected, you can retrieve audience reports, traffic breakdowns, real-time visitor data, event analytics, and conversion summaries directly from your GA4 property.

## Connection Parameters

| Parameter            | Description                                                                                                                                                                       | Required |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- |
| Service Account JSON | The full content of your Google service account JSON key file. This is the credentials object used to authenticate with the Google Analytics Data API.                            | Yes      |
| Property ID          | Your GA4 property identifier. Accepted as a plain number (e.g. `123456789`) or in the full format `properties/123456789`. Both formats are accepted and normalized automatically. | Yes      |

:::warning Minimum Permissions Required
Your service account only needs **Viewer** access on the GA4 property. Do not grant Editor or Administrator roles for service account you use in MCP Express.
:::

## Setup Guide

Follow these steps to create a service account:

### Step 1 — Create or Select a Google Cloud Project

1. Go to [Google Cloud Console](https://console.cloud.google.com/).
2. In the top navigation bar, click the project selector dropdown (next to the Google Cloud logo).
3. Click **New Project** if you do not already have one, or select an existing project.

:::note
If your organization already has a Google Cloud project used for analytics or data services, use that one to keep service accounts and billing centralized.
:::

### Step 2 — Enable the Google Analytics Data API

The Google Analytics Data API must be explicitly enabled for MCP Google Analytics integration to work.

:::note
If you run into trouble following these steps, refer to the official guide: [Enable and disable APIs](https://cloud.google.com/apis/docs/getting-started#enabling_apis).
:::

1. In Google Cloud Console, open the left navigation menu and go to **APIs & Services → Library**.
2. Search for **Google Analytics Data API**.
3. Click the result, then click **Enable**.
4. Wait for the confirmation that the API is enabled on your project.

### Step 3 — Create a Service Account

A service account is a non-human identity that MCP Express uses to authenticate with Google APIs on your behalf.

:::note
For more detail on service accounts, see: [Create service accounts](https://cloud.google.com/iam/docs/service-accounts-create).
:::

1. In Google Cloud Console, go to **IAM & Admin → Service Accounts**.
2. Click **Create Service Account**.
3. Enter a name (e.g. `mcp-express-analytics`) and an optional description.
4. Click **Create and Continue**.
5. On the "Grant this service account access to project" step, you can skip role assignment at the project level — GA4 access is granted separately in the GA4 Admin panel.
6. Click **Done**.

### Step 4 — Create and Download a JSON Key

1. On the Service Accounts list, click the service account you just created.
2. Go to the **Keys** tab.
3. Click **Add Key → Create new key**.
4. Select **JSON** and click **Create**.
5. The key file downloads automatically. Store it securely — you cannot re-download it.

:::danger Protect This File
This JSON key file grants access to your GA4 data. Do not attach it to emails, or paste its contents into any shared tool. Treat it like a password. If it is ever exposed, delete the key immediately from Google Cloud and create a new one.
:::

### Step 5 — Grant the Service Account Access in GA4

Adding the service account to Google Cloud is not enough — you must also grant it access at the GA4 property level.

:::note
For reference, see the official guide: [Add users to a property](https://support.google.com/analytics/answer/9305587).
:::

1. Go to [Google Analytics](https://analytics.google.com/) and open your GA4 property.
2. In the bottom-left corner, click **Admin**.
3. Under the **Property** column, click **Property Access Management**.
4. Click the **+** button in the top-right and select **Add users**.
5. Enter the service account's email address. It looks like: `mcp-express-analytics@your-project-id.iam.gserviceaccount.com`
   You can find this email on the Service Accounts page in Google Cloud Console.
6. Under **Direct roles**, select **Viewer**.
7. Click **Add**.

:::tip Use the Viewer Role
Viewer access is sufficient for all actions in this integration. It allows reading reports but does not permit editing property settings, goals, or audiences.
:::

### Step 6 — Find Your GA4 Property ID

1. In Google Analytics, go to **Admin → Property Settings** (under the Property column).
2. Your **Property ID** is the number shown at the top of the page (e.g. `123456789`).

:::note
Do not confuse the Property ID with the Measurement ID (which starts with `G-`). The Property ID is a numeric identifier only.
:::

### Step 7 — Validate the Connection

Once setup is complete, use the **Get Realtime Users** action with your service account and property ID to confirm the integration is working. This action requires no date range and returns live visitor data, making it the fastest way to verify credentials and access.

If you receive a permission error, double-check that:

- The service account email was added to GA4 Property Access Management (Step 5).
- The Google Analytics Data API is enabled in Google Cloud (Step 2).
- The Service Account JSON used matches the account that has GA4 access.
