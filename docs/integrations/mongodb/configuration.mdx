# Configuration

Once the MongoDB connection is validated, configuration defines how MCP Express exposes MongoDB operations as tools. Each tool binds to a collection and a single action with explicit, validated inputs.

## Tool Orchestration

MongoDB tools are action-based. You select one of the supported actions and define action-specific parameters (filters, updates, or documents). Inputs can be provided as JSON or as templated strings using `{{ }}` placeholders.

## Supported Actions

- **find**: Retrieve documents using a filter, projection, and optional limit.
- **insert_one**: Insert a single document.
- **insert_many**: Insert a list of documents.
- **update_one**: Update a single document using a filter and update query.
- **update_many**: Update multiple documents using a filter and update query.
- **delete_one**: Delete a single document using a filter.
- **delete_many**: Delete multiple documents using a filter.
- **count**: Count documents using a filter.

## Action Configuration

### find

| Field | Required | Description | Notes |
|---|---|---|---|
| filter_query | No | JSON filter used to select documents. | Defaults to `{}`. |
| projection | No | JSON projection to limit returned fields. | Optional. |
| limit | No | Maximum number of documents to return. | Non-negative integer. |

Example configuration
```json
{
  "filter_query": { "status": "active" },
  "projection": { "email": 1, "name": 1, "_id": 0 },
  "limit": 100
}
```

### insert_one

| Field | Required | Description | Notes |
|---|---|---|---|
| data | No | JSON document to insert. | If omitted, the runtime args must be the document object. |

### insert_many

| Field | Required | Description | Notes |
|---|---|---|---|
| data | No | JSON array of documents to insert. | If omitted, runtime args must be a list. |

### update_one / update_many

| Field | Required | Description | Notes |
|---|---|---|---|
| filter_query | Yes | JSON filter identifying the documents. | Required. |
| update_query | Yes | JSON update document (e.g., `$set`). | Required. |

Example configuration
```json
{
  "filter_query": { "email": "{{email}}" },
  "update_query": { "$set": { "status": "inactive" } }
}
```

### delete_one / delete_many

| Field | Required | Description | Notes |
|---|---|---|---|
| filter_query | Yes | JSON filter identifying the documents to delete. | Required. |

### count

| Field | Required | Description | Notes |
|---|---|---|---|
| filter_query | No | JSON filter to scope the count. | Defaults to `{}`. |

:::tip Test Tool Contracts Before Deployment
Use the built-in testing utility to validate filters, update documents, and templated inputs before enabling tools in production.
:::
