# Integrations

Integrations are the backbone of MCP Express, allowing you to connect your MCP servers to existing data sources and APIs. Each integration type provides specific configuration options and capabilities.

## How Integrations Work

1. **Configuration**: Each integration requires specific connection details (credentials, endpoints, etc.)
2. **Authentication**: Secure connection setup using API keys, tokens, or connection strings
3. **Tool/Resource Creation**: Define how AI models interact with your integrated systems

## Security

All integration credentials are encrypted and securely stored. MCP Express follows industry best practices for handling sensitive connection information.
